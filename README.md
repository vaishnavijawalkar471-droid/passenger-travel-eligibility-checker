✈️ Passenger Travel Eligibility Checker 
  

A beginner-friendly Python CLI application that checks whether a passenger is eligible for international travel based on age, documents, visa status, health conditions, and security rules.

Designed as a logic-heavy practice project using conditionals, loops, exception handling, and user input validation.

🚀 Features

Interactive command-line experience 

Validates:   

Age

Passport authenticity & validity

Visa availability & validity

Government ID

Security bans

Health conditions

Clear NOT ELIGIBLE exits with reasons

Final eligibility summary for approved passengers

Beginner-readable flow with clean logic

🛠️ Tech Stack

Language: Python 3

Concepts Used:

if / else

try / except

Loops

Lists

Input validation

Program flow control (exit())
